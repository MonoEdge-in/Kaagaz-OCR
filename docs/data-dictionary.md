# Data dictionary

Every table and column in the Kaagaz-OCR database, in plain English. It is written for people and for the NL-to-SQL agent. The schema is created only by the Alembic migrations in `migrations/versions/` and described by `shared/kaagaz_shared/models.py`. Change all three together.

## Rules that apply everywhere

- **Keys.** Every table has `id uuid`, generated by the database with `gen_random_uuid()`.
- **Times.** `created_at` and `updated_at` are `timestamptz` (time zone aware), set by the database. `updated_at` is refreshed by the application on every update.
- **Statuses and types** are `text` with a CHECK listing the allowed values. A value outside the list is refused.
- **Constraint names** follow one pattern: `ck_<table>_<rule>`, `uq_<table>_<columns>`, `fk_<table>_<columns>_<referred table>`, `ix_<table>_<columns>`, `pk_<table>`.

| Extension | Why |
|---|---|
| `vector` (pgvector) | Stores and indexes the search embeddings in `chunks`. Enabled by migration `0001_initial`. |

## Files and management

### folders

Virtual folders. Files never move in storage.

| Column | Type | Meaning |
|---|---|---|
| name | text | Folder name. |
| parent_id | uuid, null | The folder it sits in; null at the top. Joins `folders.id`. |
| created_by | text | Display name. |
| deleted_at | timestamptz, null | Soft delete. |

### documents

One row per unique file, recognised by its fingerprint.

| Column | Type | Meaning |
|---|---|---|
| sha256 | text, null, unique | SHA-256 of the file, 64 lowercase hex characters. Null until registered. |
| original_filename | text | Name of the first upload of this file. *Untrusted.* |
| content_type | text | MIME type. |
| size_bytes | bigint | File size in bytes. |
| storage_key | text | Where the original is kept, `originals/{sha256}.{ext}`. |
| doc_type | text, null | Set on Day 4; no allowed-value list yet. |
| status | text | `processing`, `needs_review` (waiting for a person), `published`, `failed`. Default `processing`. |
| current_step | text, null | The workflow step running now, e.g. `parse`. |
| page_count | integer, null | Number of pages (sheets for a spreadsheet), 0 or more. |
| summary | text, null | Short summary of the document. *Untrusted* if drawn from its text. |
| folder_id | uuid, null | Joins `folders.id`. |
| uploaded_by | text | Display name of the first uploader. |
| deleted_at | timestamptz, null | Soft delete. |

### uploads

One row per upload attempt, duplicates and failures included.

| Column | Type | Meaning |
|---|---|---|
| original_filename | text | The file's name as the user sent it. *Untrusted.* |
| content_type | text | MIME type the browser declared, e.g. `application/pdf`. |
| size_bytes | bigint | File size in bytes, more than 0. |
| incoming_key | text | Storage key `incoming/{upload_id}/{filename}`. |
| uploaded_by | text | Display name of the signed-in user. |
| status | text | `pending` (row made, file not yet sent), `uploaded` (file in storage), `registered` (linked to a document), `duplicate` (same file as an existing document), `failed`. Default `pending`. |
| error | text, null | Short reason when failed. Holds no document values. |
| document_id | uuid, null | The document this upload became, or matched. Joins `documents.id`. |
| workflow_id | text, null | Temporal workflow ID, `upload-{id}`. |
| completed_at | timestamptz, null | When the browser reported the upload finished. |

### audit_log

Who did what, and when. Append-only.

| Column | Type | Meaning |
|---|---|---|
| actor | text | Display name, or the worker. |
| action | text | What happened, e.g. `upload.created`. |
| entity_type | text | The kind of thing acted on, e.g. `upload`, `document`. |
| entity_id | uuid, null | Its id. No foreign key: it points into several tables. |
| details | jsonb | IDs and statuses only, never document values. Default `{}`. |

## Tags, versions and links

### tags and document_tags

`tags.name` (text, unique) is a tag. `document_tags` links a document to a tag: `document_id` and `tag_id` join `documents.id` and `tags.id`, `created_at` is when the tag was added. Deleting the document or the tag removes the link (CASCADE). It has no `id` and no `updated_at`: a link is only added or removed, never changed.

### document_versions

A corrected re-upload linked to the document it replaces. `document_id` is the new document, `supersedes_document_id` the old one (both join `documents.id`), `note` (text, null) says why, `created_by` who linked them. No CHECK yet against a document superseding itself: that rule is a Day 2 decision.

### document_links

Related documents, such as an invoice and its purchase order. `from_document_id` and `to_document_id` join `documents.id`; `link_type` (text) names the relation, free text for now. No CHECK yet against a document linking to itself: a Day 2 decision.

## Document content

- **The current run.** A document can be processed more than once. Each pass is a row in `extraction_runs`, and at most one per document has `status = 'succeeded'`: that is the current run. When a new run succeeds, the older one becomes `superseded`.
- **bbox** is `real[]`, exactly `[x0, y0, x1, y1]`: four numbers, none missing, `x0` and `y0` at least 0, `x0 <= x1` and `y0 <= y1`. Its unit depends on the page's `route`:
  - **Pixels** of the page image `pages/{document_id}/{page_no}.png` (size in `pages.width_px` and `height_px`) for `text_layer`, `ocr` and `handwriting` pages. `(0, 0)` is the top-left corner.
  - **Cell-grid units** for `spreadsheet` pages: `[col0, row0, col1, row1]`, 0-based, end excluded. Cell B7 is `[1, 6, 2, 7]`.

### pages

One row per page, or one per sheet for a spreadsheet.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. Deleting the document deletes its pages. |
| page_no | integer | 1-based. Unique per document. |
| route | text, null | `spreadsheet`, `text_layer`, `ocr` or `handwriting`; decided on Day 2. |
| image_key | text, null | Storage key `pages/{document_id}/{page_no}.png`. Null for spreadsheet pages. |
| width_px, height_px | integer, null | Page image size in pixels. Null for spreadsheet pages. |
| status | text | `pending`, `done`, `failed`. |

### extraction_runs

One pass of the pipeline over a document.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. |
| pipeline_version | text | Which code version ran. |
| models | jsonb | Which model or engine did each step. |
| status | text | `running`, `succeeded`, `failed`, `superseded`. At most one `succeeded` row per document. |
| started_at, finished_at | timestamptz, finished_at null | When the run started and ended. |
| error | text, null | Short reason on failure. Holds no document values. |

### blocks

Every piece of a page, in reading order.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. |
| page_id | uuid | Joins `pages.id`, always on the same document (a combined foreign key). |
| block_no | integer | Order within the page. |
| block_type | text | `heading`, `paragraph`, `table`, `table_cell`, `stamp`, `signature`, `handwriting`, `figure`. |
| text | text, null | *Untrusted.* What the reader saw. Never overwritten by a later correction. |
| bbox | real[] | Where the block sits on the page (see above). |
| confidence | real, null | The reader's confidence, 0 to 1. |
| source | text | Which engine produced this block, e.g. `pdfplumber`. |
| parent_block_id | uuid, null | The block this one sits inside, e.g. a table cell's table. Joins `blocks.id`. |
| extraction_run_id | uuid | Which run produced this block. Joins `extraction_runs.id`. |

## Extraction and quality

### invoices

The first typed document table. Every extracted column is nullable: a misread value is still stored and sent to review rather than dropped.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. |
| extraction_run_id | uuid | Which run produced this row. Joins `extraction_runs.id`. |
| invoice_no, vendor_name, vendor_gstin, currency | text, null | *Untrusted* where read from the document. |
| invoice_date, due_date, received_on | date, null | |
| subtotal, tax_total, total | numeric(14,2), null | Money, in `currency`. |

No unique constraint: one document can hold several invoices.

### invoice_lines

One row per invoice line.

| Column | Type | Meaning |
|---|---|---|
| invoice_id | uuid | Joins `invoices.id`. Deleting the invoice deletes its lines. |
| line_no | integer | Order on the invoice. Unique per invoice. |
| description, hsn_code | text, null | *Untrusted.* |
| quantity | numeric(14,3), null | |
| unit_price | numeric(14,4), null | Four decimals, so `quantity x unit_price` checks don't fail on rounding. |
| amount | numeric(14,2), null | |

### extracted_fields

Fields for a document type that has no table of its own yet.

| Column | Type | Meaning |
|---|---|---|
| document_id, extraction_run_id | uuid | Same as invoices. |
| doc_type | text | The classified type, e.g. `unknown`. |
| data | jsonb | Key and value pairs. *Untrusted.* |

### field_sources

Where one extracted value came from. Required on every value stored as fact: no field_sources row means the value isn't traceable, so it stays out of the typed tables or goes to review instead.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. |
| table_name | text | `invoices`, `invoice_lines` or `extracted_fields`: which table the value lives in. |
| row_id | uuid | The row in that table. No foreign key: it points into more than one table. |
| column_name | text | Which column. |
| block_id | uuid | The block the value was read from. Joins `blocks.id`. Never null. |
| page_no | integer | Must be a real page of the same document (a combined foreign key with `document_id`). |
| bbox | real[] | Where on the page (see "Document content" above). Never null. |
| model | text | Which model or engine read it, e.g. `qwen3.5:4b`. |
| confidence | real | 0 to 1. Never null. |
| reviewed_by, reviewed_at | text, timestamptz, both null | Set once a person confirms or corrects the value. |

## Review and search

### review_tasks

A value waiting for a person to check it, opened when extraction can't map a value to its source or a validation rule fails.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. |
| table_name | text | `invoices`, `invoice_lines` or `extracted_fields`, same list as field_sources. |
| row_id | uuid | The row in that table. No foreign key. |
| column_name | text | Which column. |
| reason | text | Why review is needed, e.g. `no_source`. |
| current_value, corrected_value | text, both null | The value as read, and the person's correction once resolved. |
| status | text | `open`, `resolved`. Default `open`. |
| resolved_by, resolved_at | text, timestamptz, both null | Set once resolved. |

### chunks

Searchable pieces of a document's text, for hybrid search.

| Column | Type | Meaning |
|---|---|---|
| document_id | uuid | Joins `documents.id`. |
| chunk_no | integer | Order within the document. Unique per document. |
| page_from, page_to | integer | The page range this chunk covers. `page_to >= page_from`. |
| section_path | text, null | Which heading this chunk sits under. |
| header | text, null | A short context header shown with search results. |
| text | text | *Untrusted.* The chunk's content. |
| embedding | vector(1024), null | Filled on Day 5 by Qwen3-Embedding-0.6B. A `HNSW` index (cosine distance) ranks by meaning. |
| tsv | tsvector, generated | Built from `header` and `text` in English. A `GIN` index supports full-text search. |
