# Data dictionary

Every table and column in the Kaagaz-OCR database, in plain English. It is written for people and for the NL-to-SQL agent. The schema is created only by the Alembic migrations in `migrations/versions/` and described by `shared/kaagaz_shared/models.py`. Change all three together.

## Rules that apply everywhere

- **Keys.** Every table has `id uuid`, generated by the database with `gen_random_uuid()`.
- **Times.** `created_at` and `updated_at` are `timestamptz` (time zone aware), set by the database. `updated_at` is refreshed by the application on every update.
- **Statuses and types** are `text` with a CHECK listing the allowed values. A value outside the list is refused.
- **Constraint names** follow one pattern: `ck_<table>_<rule>`, `uq_<table>_<columns>`, `fk_<table>_<columns>_<referred table>`, `ix_<table>_<columns>`, `pk_<table>`.
